# Ambulance Dispatch – Nearest Ambulance Allocation System

A college-level Java Spring Boot CRUD web application that manages ambulance availability, emergency calls, city zones, and emergency dispatch allocation.

## How to Run
```powershell
mvn spring-boot:run
```
Or for instant testing without MySQL:
```powershell
mvn spring-boot:run "-Dspring-boot.run.profiles=h2"
```
Access at: http://localhost:8080/
